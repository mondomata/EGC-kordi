Hiánypótló weboldal: Egységes Országos Vetületi Rendszer (EOV), GPS rendszer, valamint Cím keresést 
tesz lehetővé, térképi támogatással, automatikus EOV/GPS konverzióval.

1. A címkeresés a házszám pontosság érdekeben Google térképpel működik.
2. A google GPS koordináták gyorsan átmásolhatók az EGC-be.
3. Az EGC az OpenStreetMapon mutatja a pozíciót, azonnal konvertálja és kiírja az adatokat EOV és GPs paraméterekkel is.
4. Meglévő EOV adatok manuális beírásával azonnal GPS formátumban is kinyerhetők adatok, és GPS-ből EOV is.
